# AMUConnect

A collaborative web platform that helps Aix-Marseille University students ask questions, share resources, and support each other.

## Features

- User authentication
- Create and manage posts
- Student collaboration
- Responsive interface

## Tech Stack

- Flask
- HTML
- CSS
- JavaScript
- SQL

## Project Structure

AMUConnect/
├── backend/
├── frontend/
├── assets/
└── README.md

## Installation

```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```
